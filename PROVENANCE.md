# Provenance

Tuplo began as a university distributed-systems assignment at IST ("DIDA-TUPLE", MEIC, 2018–19). This repository is
a **clean-room Java reimplementation and expansion** written from an understanding of the problem, not a port of any
prior code.

- The original C# solution (by a former project group) and the course's assignment PDF are **not** included here —
  they are third-party/course material and stay out of the public tree (kept locally under a git-ignored `reference/`).
- All code in this repository is original work, licensed under [Apache-2.0](LICENSE).
- The semantics Tuplo targets are described in our own words in [docs/SPEC.md](docs/SPEC.md).

Tuplo is its own project now: a teaching-first, distributed, fault-tolerant tuple space.
