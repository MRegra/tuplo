# Posts

Write-ups that explain Tuplo's algorithms, one post per step of the build. They are published on the author's
blog. This folder only links to the published versions.

## Published

_None yet. Links appear here once each post is live._

## Drafts

Drafts are not part of this repository. Everything in `docs/posts/` except this README is gitignored, so a draft
can sit here locally without being committed. CI runs [`scripts/check-no-draft-posts.sh`](../../scripts/check-no-draft-posts.sh),
which fails if any committed Markdown file has `status: draft` in its front matter.
